# Legacy Full-State SOP vs TTNO Results

This directory preserves the job 99434 array output and earlier local runs:

- full-state SOP and TTNO apply/build timings;
- lead, phonon, and synthetic shared-structure scans;
- per-point CSV files and Slurm logs;
- generated figures, notebook, and summary Markdown.

These results predate the local effective-Hamiltonian environment benchmark.
They do not represent either `sop_mctdh_like_state_env` or an all-node sweep,
so they are excluded from the strict scaling figure.
